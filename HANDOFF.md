## Done
- Persona 5–style personal site (`index.html`, `styles.css`, `main.js`), 5 languages in `i18n.js`
  (EN / 繁 / 日 / 한 / FR), loading screen, star-shaped stats chart, quests, origin, volunteering,
  achievements (with logos), articles, confidants with QS ranks. All logos are local files in `assets/logos/`.
- 3D walk-around (`world.js`, three.js vendored in `assets/vendor/`), **hidden on the live site**
  (`const LIVE = false` in `world.js`); preview with `?scene=preview`.
  - Avatar: Tripo model from `assets/ref/white/` (front/right/back), rigged, optimised to
    `assets/models/avatar.glb` (751 KB). Tripo's own retarget endpoint fails on this rig (error 1004),
    so the walk/idle/run are Mixamo clips (`assets/models/motion.glb`, from three.js Xbot) retargeted
    in the browser by matching limb directions (`buildMap` / `retarget` in `world.js`).
  - Scenes: UPenn + CUHK use stitched reference paintings as backdrops (`assets/world/`);
    Central loads six Tripo landmark models from `assets/models/hk/*.glb` (generated by the
    `tripo-buildings` GitHub Action — check it finished) with block fallbacks.
- Tripo runs in GitHub Actions using the `TRIPO_API_KEY` repo secret (`tools/tripo/*.sh`).
  Credits: ~1000 at start; ~90 spent on the avatar, ~240 expected for the six buildings.

## Rainy-evening rebuild (done, awaiting user review)
- `world.js` now renders all three areas as P5R-style rainy evening streets: EffectComposer
  (outlined cel pass -> UnrealBloom -> ACES -> cool grade + vignette + grain), wet ground via
  `Reflector` with a custom smeared/rippled shader (`GroundShader`, albedo + wetness canvases per area),
  GPU rain streaks + splash rings, silhouette crowds (`NPC`), procedural shop-house rows with neon
  (`shopRow`), vending machines, poles + wires, guardrails, bikes, etc. Low over-the-shoulder chase
  camera; WASD is camera-relative. Hero picks up the colour of nearby lights (4 roaming point lights)
  plus a rim-light shader patch (`rimify`). Extra vendored addons: postprocessing/, shaders/, objects/Reflector.
- Walk fix: the Tripo legs are hip -> knee -> ankle with two sibling foot bones (toe + heel). One leg was
  mapped through the heel bone (foot turned backwards); now `LEGS` maps ankle->toe and the heel bone
  follows the ankle, and the Mixamo hips rotation drives the rig root. Checked from the side in headless renders.
- The style video was NOT available in the cloud session (it lives on the user's machine), so the look
  is built from the notes above; compare against the video and tune colours/density.
- Debug: `?scene=preview&debug` exposes `window.__world` (`step`, `render()` -> dataURL) for headless snapshots.

## Five areas + inspectable landmarks (done)
- `world.js`: Central, UPenn, CUHK, Singapore (Marina Bay), New York, each a 120 m walk (`L = 60`) with zones.
  Landmarks get a spot (`spot(A, key, x, z, r, look)`): floating "!" marker, E/tap -> camera frames `look`,
  dialog shows `TXT[lang].s[key] = [name, line]` (5 languages). Singapore/NY landmarks are procedural
  (the user's SG/NY reference images were only pasted in chat, not saved to the repo).
- Ground: one Reflector per area painted along its full length (`wetGround` + `painter`), water via `water()`
  with `cuts` discarding ground over it.
- Crypto Quest game cancelled by the user; its i18n strings were removed.

## Avatar
- `assets/models/avatar-v3.glb` (loaded first): Tripo v3.1 (detailed geometry, extreme texture) from an AI-refined front view
  (`assets/ref/white-hq/front-ai-1.png`, face matched to `white-sheet-detail.webp`) + right/back crops; rigged; ~1.9 MB.
- Walk: the Mixamo clips are retargeted *relative to the mocap's idle stance* onto the character's relaxed stance
  (`buildMap(rig, owner)` / `retarget(rig, owner)`), which fixed the backward-bent arms/hands and head tilt.
- Pipeline: `tools/tripo/avatar3.sh` stages `prep` / `build <front>` / `rig <task>` / `fetch <task>` via `RUN_AVATAR3`.
